# Screenshots

These files are embedded in the root [`README.md`](../README.md) and the pages under
[`docs/`](../docs), and are regenerated
with [`scripts/make_screenshots.js`](../scripts/make_screenshots.js) (panel) and
[`scripts/make_card_screenshots.js`](../scripts/make_card_screenshots.js) (card) against a
running sandbox. The demo installation there has flow rates on every zone and a
Cycle & Soak slot ("Weekly deep soak"), so the water and rest figures show up.

| File | Content |
|------|---------|
| `overview.png` | Overview tab — current run, next runs, watering mode |
| `zones.png` | Zones tab — list with modes, exclusive and issue filters |
| `zone_edit.png` | Zone editor — sections with their summaries, Outputs open |
| `zone_edit_advanced.png` | Zone editor — Start service section (preset, duration field, start target) |
| `zone_edit_water.png` | Zone editor — Water section (meter entity, flow rate) with its help expanded |
| `schedule.png` | Schedule tab — cycles and slots, a cycle expanded to its 14-day strip |
| `cycle_wizard.png` | New irrigation cycle wizard — live 14-day preview |
| `schedule_edit.png` | Slot editor — sections with their summaries, When open (weekdays, start time, week cycle) |
| `schedule_edit_cycle_soak.png` | Slot editor — Cycle & Soak (repetitions, rests) with its help expanded |
| `timetable.png` | Timetable tab — weekly grid (zones × weekdays, time-of-day rows) |
| `settings.png` | Settings tab — every section closed to a line that says what is set |
| `card_status.png` | Dashboard card — status view |
| `card_zones.png` | Dashboard card — zones view |
| `card_schedule.png` | Dashboard card — schedule view |
| `card_week.png` | Dashboard card — week view |
| `card_run.png` | Dashboard card — manual run picker |
| `card_compact.png` | Dashboard card — compact tile |
| `card_editor.png` | Dashboard card — visual editor, Interactions section |
| `simple_irrigation_logo.png` | Logo used in the README header |
